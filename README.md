# NIA — Nectar Intelligence Agent

AI-powered customer support agent built for the Hiver SDE Intern take-home assignment.

## Objective

NIA is designed to:

1. Classify incoming customer-support messages into intents.
2. Retrieve relevant historical support conversations.
3. Draft replies grounded in historical resolutions.
4. Decide whether a message should be auto-handled or escalated to a human.
5. Evaluate the system using a manually labelled golden evaluation set.

## Project Structure

- `data/` — dataset documentation and local data
- `notebooks/` — exploratory analysis
- `src/` — AI pipeline
- `evaluation/` — evaluation scripts
- `experiments/` — experiment results
- `report/` — final report
- `tests/` — automated tests
